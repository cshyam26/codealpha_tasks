
# LinguaAI — Language Translation Tool

A responsive multilingual translation web application built
for the CodeAlpha Artificial Intelligence Internship.

## Features
- Source and target language selection
- English-to-Hindi and multilingual translation
- Language swapping
- Copy translated text
- Browser text-to-speech
- Input validation and error handling
- Responsive dark-themed interface

## Technologies
- HTML, CSS, JavaScript
- Node.js and Express
- MyMemory Translation API
- Public Google Translate endpoint

## Run Locally

1. Install Node.js.
2. Clone this repository.
3. Open the project folder in a terminal.
4. Run `npm install`.
5. Run `npm run dev`.
6. Open http://localhost:3000.

An internet connection is required for translation.

## Limitations
The application uses public translation endpoints
without an API key. Availability and translation
quality are not guaranteed.
